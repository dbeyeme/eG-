# Voyageur Mobile UI

## Workflow

1. Modifier `scss/` (pas seulement le CSS compilé si source existe).
2. Réutiliser `variables.scss` et partials (`_home.scss`, `_form.scss`, …).
3. Respecter mobile portrait + header fixe existant.
4. Accent `#58d68d` ; pas de thème purple/cream générique.

## Checklist

- [ ] Cohérent avec pages voisines
- [ ] Touch targets utilisables
- [ ] Pas de cards inutiles dans le hero/accueil
